# GainsPlan PRO — Zaawansowany Planer Diety Masowej (~3300–3470 kcal)

Kompleksowa aplikacja webowa do zarządzania planem żywieniowym na masę mięśniową, zoptymalizowana pod maksymalną wygodę (batch-cooking, dynamiczna lista zakupów, baza produktów i przepisów).

---

## 🚀 Jak uruchomić?

1. **Lokalnie (Szybki start):** Otwórz plik `index.html` bezpośrednio w dowolnej nowoczesnej przeglądarce.
2. **Serwer Node.js:**
   ```bash
   node server.js
   ```
   Aplikacja będzie dostępna pod adresem: [http://localhost:4321](http://localhost:4321).
3. **Uruchomienie skryptem:** Kliknij dwukrotnie `start.bat`.

---

## 🌟 Kluczowe Funkcjonalności

- **Pełny 7-dniowy harmonogram (Poniedziałek – Niedziela):**
  - **Śniadanie (Super-Szejki 1110–1150 kcal):** Szejk Chałwowy (100g chałwy), Szejk Bounty ze Skyrem, Szejk Szarlotkowy z daktylami.
  - **Obiad (880–970 kcal):** System batch-cooking (gotowanie na 2 dni: Makaron z mięsem w kremowym sosie pomidorowym, Ulepszony Meksykanin z wołowiną, Makaron ze szpinakiem i kurczakiem, Świeże podwójne wrapy).
  - **Kolacja (610–680 kcal):** Chrupiące tosty żytnie z mozzarellą, Włoska bruschetta z szynką dojrzewającą, Domowa quesadilla z patelni, Jajecznica z 3 jaj na maśle ze szczypiorkiem.
  - **Nocny Gainer (680 kcal):** Hi Tec Whey Mass Builder + WPC 80% + Kreatyna (54g białka w 1 minutę).
- **Zsynchronizowany Bilans Makro:** Każdy dzień precyzyjnie zbilansowany w oknie **3290–3460 kcal** oraz **182–198 g pełnowartościowego białka**.
- **Auto-Kalkulator & Baza 60 Produktów:** Dokładne wartości odżywcze per 100g z inteligentnym dopasowywaniem aliasów składników.
- **Dynamiczna Lista Zakupów (2 / 4 / 7 dni):**
  - Automatyczne mnożenie składników x2 dla dań gotowanych na dwa dni.
  - Konsolidacja produktów (np. łączenie pieczywa, makaronów, passaty pod jedną pozycją).
  - Podział na sekcje sklepowe (Nabiał, Mięso, Owoce/Warzywa, Suche, Tłuszcze, Suplementy).
  - Interaktywny checkbox z zapamiętywaniem stanu koszyka.
- **Pamięć lokalna (LocalStorage):** Zapisywanie odhaczonych posiłków, własnych przepisów, produktów oraz stanu koszyka.
- **Responsive Web Design:** Dopasowany interfejs na desktop, tablet i smartfon (możliwość instalacji jako PWA na telefonie).
